# Fitts & Posner 三阶段模型（动作如何变自动）

## 一、概念与定义

Paul Fitts 与 Michael Posner 在 1967 年提出技能习得的**三阶段模型**，是最早系统描述「人如何把一件事从『费脑子』变成『不用想』」的理论之一。三个阶段是：

1. **认知阶段（Cognitive）**：学习者努力理解任务是什么、有哪些步骤，大量依赖外部指导与语言化思考，错误多、速度慢。
2. **联结阶段（Associative）**：通过练习把正确步骤「联结」起来，错误减少，开始能根据情境微调，但仍有意识控制。
3. **自动化阶段（Autonomous）**：动作高度流畅、几乎不占注意力，能在干扰下执行，甚至「边做边想别的」。

这个模型与 Dreyfus 五阶段是「挛生理论」：Fitts 偏重**动作/运动控制**视角，Dreyfus 偏重**决策依据**视角。二者合起来，完整解释了「从学骑车时浑身紧绷，到后来单手扶把还能聊天」这类现象。

## 二、可核验出处

- Fitts, P. M., & Posner, M. I. (1967). *Human Performance*. Brooks/Cole. （第三章提出三阶段模型）
- 后续被广泛引用为「Fitts-Posner 三阶段」或「认知-联结-自动化」。
- 与 Adams (1971) 的「闭环-开环」运动学习理论互补。

## 三、关键证据与实验

经典证据来自**追踪任务（tracking task）**实验：让被试用操纵杆追踪移动目标。认知阶段被试紧盯每一步、言语报告冗长；联结阶段反应变快、报告变短；自动化阶段被试能一边追踪一边做别的事，且追踪质量不降。这直接证明「注意力占用」随阶段递减。

另一证据是**双重任务损耗**：自动化阶段的技能在叠加第二任务时性能下降很小，而认知阶段会崩溃。这成为判断「是否真自动化」的操作性标准——self-master-agent 虽不直接测双重任务，但 `measure` 自评 + `drill` 实战的组合，间接检验你是否已脱离「全神贯注才能做对」的阶段。

## 四、与 self-master-agent 的关联

- `ladder` 的 L1–L2 大致对应认知+联结阶段（仍需意识控制），L3–L5 对应自动化阶段（流畅、可迁移）。
- 引擎的晋升要求「真实实战成功」而非「能讲步骤」，正是 Fitts 的判据：**自动化只能由真实表现证明，不能由口头理解证明**。
- `drill --confidence`（自信度）可与「阶段」互证：认知阶段自信低且波动，自动化阶段自信稳。

## 五、实践落地（如何在引擎里用）

1. 定义 ladder 判据时，低层写「能一步步做对（认知）」，高层写「能流畅且分心下做对（自动）」。
2. 用 `drill` 记录「这次是否几乎不费力」——当连续多次低费力成功，说明进入自动化，可瞄下一层。
3. 若 measure 自评高但 drill 仍需全神贯注，说明停在联结阶段，未自动，别急着晋升。

## 六、协同网络

- 与 **Dreyfus 五阶段**：Fitts 是动作视角，Dreyfus 是决策视角，互为表里。
- 与 **ACT-R 程序性知识**：自动化阶段 = 程序性知识编译完成。
- 与 **认知负荷（Sweller）**：自动化释放工作记忆，正是负荷下降的体现。
- 与 **心流**：自动化+适度挑战 = 进入心流的物质基础。

## 十一、误区追问

问：小孩子学语言算自动化吗？答：算，且因脑可塑期更易；成人需更多刻意重复才能达到同等流畅。

问：自动化了还需要专注吗？答：日常执行不需要，但突破到新难度仍需重新专注，自动化不消灭学习。

问：为什么老司机还会出事？答：过度自动化+分心时，遇罕见情境反应慢；需保留「元监控」兜底。


## 十二、深度问答（六个常见疑问）

问：认知阶段要多久？答：简单技能几天，复杂技能数周，取决于表征复杂度。

问：能否跳过认知阶段直接练？答：不能，缺了「理解做什么」会建立错误联结，后期更难改。

问：自动化后会退步吗？答：会，停用则生疏；用间隔复习式的 drill 维持。

问：联结阶段最容易犯什么错？答：过早追求速度导致错误固化，应先准后快。

问：怎么测自己到自动化了？答：双重任务测试——边做别边做，质量不降即自动化。

问：三阶段和心流怎么配合？答：自动化是进入心流的物质基础，二者协同加速登顶。


## 十三、一轮登顶实战推演（以「开车」为例）

- 认知阶段：教练旁坐，你默念「踩离合-挂挡-松手刹」，全神贯注，错误多。
- 联结阶段：独自上路，步骤已连贯，但遇突发仍要思考；drill 记录「是否还需念步骤」。
- 自动化阶段：能边开车边聊天、调空调，双重任务不降质；此时 report 可判你达 L4。
- 注意：自动化后遇冰雪等罕见情境仍要回到专注，保留元监控，别完全放手。


## 十四、速查总图：三阶段↔注意力占用

```
认知   → 全神贯注、念步骤      → drill「是否需念步骤」=是
联结   → 连贯但遇变仍思        → drill 记录过渡
自动   → 分心不降质           → 双重任务验证
```
晋升看「真实表现」而非「口头理解」；measure 高但需全力=停联结阶段。
