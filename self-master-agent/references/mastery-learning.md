# 掌握学习（Mastery Learning）

## 一、概念与定义

Benjamin Bloom 在 1968 年提出、1971 年系统化的「掌握学习（Mastery Learning）」主张：**只要给足时间与恰当教学，绝大多数学生都能达到『掌握』标准**，而非正态分布里只有少数拔尖。其核心操作是「单元化 + 形成性评估 + 未达标就补教重测」，直到人人过关再进下一单元。

这对 self-master-agent 的阶梯设计是直接的祖先：我们的 L1→L5 也是「一级没真正掌握，就不晋下一级」的逻辑。掌握学习颠覆了「天赋决定论」，与 Bloom 后来的天才研究（1985）形成闭环——**掌握是登顶的底座**。

## 二、可核验出处

- Bloom, B. S. (1968). *Learning for Mastery*. **UCLA Evaluation Comment, 1(2).**
- Bloom, B. S. (1971). *Mastery Learning*. 收录于 *Handbook of Formative and Summative Evaluation*.
- 元分析：Kulik, Kulik & Bangert-Drowns (1990) 确认掌握学习对成绩有中等正向效应。
- Hattie (2009, *Visible Learning*) 把「形成性评估」列为高效应量的教学因子。

## 三、关键证据与实验

Bloom 的经典对比：传统班级按固定节奏走，成绩呈钟形分布；掌握学习班允许慢者补教重测，最终成绩分布整体上移，大量学生达到原先只有少数能达到的水平。这说明**差异主要来自「是否给足达成掌握的机会」，而非能力天花板**。

另一证据是「形成性评估」的价值：频繁的低 stakes 测验让学生及时知道哪没懂，避免错误积累。这正是 self-master-agent `measure` + `report` 的设计哲学——用高频自评与弱项预警替代期末「一考定生死」。

## 四、与 self-master-agent 的关联

- `ladder` 的逐级判据 = 掌握学习的「单元掌握标准」。
- 引擎「未达晋升门槛（3 次实战 + 自评）就不晋下级」= 掌握学习的「未达标补练重测」。
- `plan` 给的补练清单 = 掌握学习的「补教」。
- `report` 弱项预警 = 形成性评估的自动化版。

## 五、实践落地（如何在引擎里用）

1. 定义 ladder 时，把每层写成「可判定的掌握标准」，而非模糊目标。
2. 别跳级：plan 说还差几次就真去 drill，像掌握学习一样「过关再走」。
3. 把 measure 当形成性评估用——每周一次，及时发现未掌握点。

## 六、协同网络

- 与 **Bloom 天才研究**：掌握是登顶底座，天才研究是掌握到极致的结果。
- 与 **刻意练习**：掌握学习提供「节奏」，刻意练习提供「每次怎么练」。
- 与 **测试/提取效应**：高频 measure 即低 stakes 测验。
- 与 **成长型思维**：掌握学习否定天赋天花板，与 Dweck 同源。

## 十一、误区追问

问：掌握学习会不会拖慢进度？答：短期慢，长期整体水平更高，且减少「夹生」导致的返工。

问：所有人都掌握现实吗？答：需足够师资/反馈资源；个人用本引擎可近似实现「自我掌握学习」。

问：掌握标准谁定？答：由 ladder 判据定，判据越具体可核验，掌握越真。


## 十二、深度问答（六个常见疑问）

问：掌握学习在大班可行吗？答：传统大班难，但翻转课堂 + 自适应工具可部分实现。

问：掌握标准定太高会卡死吗？答：会，标准应「可达但需努力」，本引擎 ladder 由你自定正合适。

问：补教要无限次吗？答：不必，给足 2-3 次补练重测通常足够，卡死说明方法错。

问：掌握学习和精通（L4）关系？答：掌握是每层「过关」，精通是多层掌握后的质变。

问：成人自学怎么用掌握学习？答：自定单元 + 周 measure + 未达标就补 drill，即自学版掌握学习。

问：它和考试冲突吗？答：不冲突，只是把「一考定终身」改成「形成性多次评估」。


## 十三、一轮登顶实战推演（以「学日语 N2」为例）

- 单元化：把 N2 拆成「语法/听力/读解」单元，ladder 每层写可判定掌握标准。
- 形成性评估：每周 measure 自测，不等地等到考试。
- 未达标补教：若某语法单元 drill 不足，plan 显示缺口，补练重测再晋下级。
- 不跳级：即使阅读强，也不跳过听力单元；报告弱项会提示「听力未掌握」避免夹生。
- 结果：整体稳过 N2，而非偏科险过。


## 十四、速查总图：掌握学习循环↔引擎

```
单元化      → ladder 分层
形成性评估  → measure 周测
未达标补教  → plan 给缺口+补 drill
不跳级      → 晋下级需双条件
```
结果：整体水平上移，避免「夹生」导致的后期返工。
