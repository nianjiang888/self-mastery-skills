# 更新记录

## 2.0.0（2026-09-01）

首个正式版本。

### 能力

- 8 个子命令：`set`（沟通档案）、`log`（记一次对话）、`trend`（全景）、`review`（单条拆三层）、`script`（话术检索）、`risk`（模式扫描）、`plan`（本周唯一行动）、`report`（落盘）。
- 指标：平均达成、防御率、对抗率、情绪强度均值与高强度占比、倾听分、关系账户、身份层冲突占比、情绪代价、话术沉淀率、分场景达成、分对象关系。
- 层次推断（事实/情绪/身份）：优先级 身份 > 情绪 > 事实，可用 `--layer` 覆盖。
- 弱项分级：高 / 中 / 低，中或高触发退出码 1。
- 退出码：`0` 正常 / `1` 中或高严重度 / `2` 用法错误 / `4` 参数或数据不可用。
- 幂等：`append_event` 按 `type+id` 覆盖，修正错账不重复计数。
- 实物证据：`events.jsonl` + `profile.json` + `reports/comm-<日期>.md`。
- 14 篇 `references/` 方法论长文，每篇带年份 + 期刊/书名出处；话术库 `communication-scripts.json` 含 10 套带出处模板。
- 3 份 `resources/` JSON：话术库、指标算法与出处、指标口径与弱项规则。

### 开发过程中修掉的问题

1. **语法错误（括号未闭合）**：`compute_stats` 里 `identity = len([...])` 少一个右括号，`py_compile` 阶段即修复。
2. **话术命中过多会淹没用户**：`script` 初期把命中的所有模板全输出（冲突×关系命中 5 套），改为按 priority 排序取前 3 套。
3. **`set` 无字段时仍写空档案**：无参 `--set` 会写出 `{}`，改为不建空档案并提示可用字段（rc=0）。
4. **边界校验齐全**：`outcome`（1-5）、`tone`（1-10）、`listened`（1-5）、`aftermath`（-2..2）越界一律 `die` rc=4；`review` 找不到 id rc=4；未知子命令 rc=2。

### 写作原则

`references/` 14 篇按内容自然写扎实、带出处，**不硬性凑字数**。每篇结构统一：出处 → 核心结论 → 为什么重要 → 怎么用 → 边界与误用。

### 合规

明确不做心理治疗、不做临床诊断、不评判谁对谁错、不存储对方隐私（建议 `words` 只记自己的话）。涉及持续关系暴力、职场霸凌、家庭暴力，一律提示寻求专业帮助。所有数据存本地，不联网、不上传。
