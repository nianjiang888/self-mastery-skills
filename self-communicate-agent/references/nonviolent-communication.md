# 非暴力沟通四步

## 出处

Rosenberg, M. B. (2003). *Nonviolent Communication: A Language of Life*（2nd ed.）. PuddleDancer Press.
核心思想源自 Carl Rogers 关于人本主义心理咨询与「无条件积极关注」的工作。

## 核心结论

Rosenberg 的观察是：**绝大多数冲突的语言里藏着对对方的评判，而评判是沟通的终止符。** 一旦对方听到指责，他的全部注意力会转向自我保护（辩解、反击、沉默），你真正想说的话一句也进不去。

他给了一个四步结构替代评判：

1. **观察**——只说事实，不带评价。「这周三次会你晚到十分钟」，不是「你总是迟到」。关键区别在于：事实可以被验证，评判会引发反驳。
2. **感受**——说你自己的情绪，用情绪词。「我着急」「我有点失落」。注意「我觉得你不重视我」不是感受，是伪装成感受的指责。
3. **需要**——说出你真正在意的东西。「我需要能按计划推进」。
4. **请求**——具体、可执行、可以拒绝。「下次能不能提前五分钟？来不及的话发我一条消息也行」。

## 为什么顺序不能乱

这四个步骤是从**最不可能引发防御**到**最需要对方配合**排列的。观察是最中性的；感受在表达脆弱，通常能降低对方的戒备；需要是在解释自己而不是要求对方；请求才是真正要对方做出改变，放在最后，此时对方的防御已经降到最低。

反过来做——先提要求，再说理由，最后被拒绝时开始评价对方——是把顺序完全颠倒，几乎必然失败。

## 怎么用

- 本引擎的话术库里，NVC 四步是**优先级最高的模板**（priority 1），适用于冲突、亲密关系、反馈三类场景。
- `review` 子命令判断某次对话卡在「身份层」时，给的换法「把『你不对』换成『我的理解是…』」就是 NVC 第一步的应用——把评判还原成观察。
- **只练第一步也能见效**。把「你从来都不…」换成具体的时间、次数、场景，是投入产出比最高的一个动作。

## 边界与误用

- **NVC 不是话术套路**。如果内心在想「用这个技巧让对方就范」，对方会察觉。Rosenberg 强调意图比措辞重要——这套语言的目的是建立连接，不是赢。
- **不是所有场景都适用**。紧急情况下需要直接指令（「快躲开」），此时四步反而添乱。
- **它不能保证对方配合**。NVC 改变的是你这一侧的表达质量，对方依然可能拒绝。请求之所以叫请求，就是因为它允许被拒绝。
- 本引擎提供的是模板，不是训练。真正的改变发生在你实际开口的那些时刻。
