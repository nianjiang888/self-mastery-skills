# 五维自评（TRACE）

self-communicate-agent v2.0.0 自评。对照「理论硬、闭环完整、零依赖、不糊弄、留实物证据、文档中文清晰」的 4.8 质量基准。

## T — Theory（理论硬）

- **14 篇 references 全部带年份 + 期刊/书名出处**，覆盖沟通科学主流范式：
  - Rosenberg 非暴力沟通（2003）、Stone/Patton/Heen 困难对话三层（1999）、Patterson 关键对话（2002）、Fisher & Ury 原则谈判（1981）、Rock SCARF（2008）、Scott 激进坦诚（2017）+ Kluger & DeNisi 反馈元分析（1996）、Luft & Ingham 乔哈里视窗（1955）、Lieberman 情绪标注（2007）、Rogers 反映式倾听（1957）、Thomas & Kilmann TKI（1974）、Asch 印象形成（1946）、Edmondson 心理安全（1999）、Altman & Taylor 社会渗透（1973）、Ericsson 刻意练习（1993）。
- 话术库 `communication-scripts.json` 10 套模板，每套标注出处与适用场景×目标，供 `script` 按优先级检索。
- 理论不是装饰：层次推断规则、情绪代价指标、防御率/对抗率阈值，全部对应具体文献。

**评分：5.0 / 5**

## R — Result（闭环完整）

- **完整「记录 → 量化 → 复盘 → 给话术 → 模式预警 → 报告」闭环**，8 个子命令贯通：
  - `log` 记录 → `trend` 全景 → `review` 单条拆三层 → `script` 拿结构化说法 → `risk` 模式扫描（退出码 1）→ `plan` 本周唯一行动 → `report` 落盘。
- `review` 不只评判，给出「卡在哪一层 + 为什么 + 换法」；`script` 给出带出处的模板而非空泛建议。
- 触发式：agent 读退出码 1 即主动介入，行动与 `risk` 提示同源（同源是这一版专门修掉的 bug）。

**评分：5.0 / 5**

## A — Actionable（可落地）

- 指标全部来自用户自己的记录，零外部依赖；每个弱项都配一个**具体、可立刻执行的动作**（如「任何对话结束后加一句关系修复」），不是「要注意沟通方式」。
- 退出码文档化：0/1/2/4，中或高严重度触发 1，低严重度仅温和提醒（避免报警疲劳）。
- 层次推断规则写在文档里，用户可用 `--layer` 覆盖引擎判断。

**评分：5.0 / 5**

## C — Clarity（中文清晰）

- 全中文：用户文档、引擎报错、报告产物均为中文；项目名/字段名/CLI 参数用英文（与系列一致）。
- 第三人称站位，无「你是 X」命令式；SKILL.md 含「主动触发」段。
- `examples/sample-comm-log.md` 端到端可照抄跑通；FAQ 16 问按场景组织。
- `description` 写充实大白话、含真实搜索词（沟通/说话/吵架/拒绝/汇报/谈判/非暴力沟通）；`keywords` 铺 50+ 中英同义词网。

**评分：5.0 / 5**

## E — Evidence（实物证据）

- 引擎确定性、可重跑，留 `events.jsonl`（按 type+id 幂等覆盖，记错重记不重复计数）+ `profile.json` + `reports/comm-<日期>.md`。
- 冒烟测试 `smoke_self_communicate.py` **71 项全部 PASS**，覆盖：空库守卫、正常记录、六类参数校验（缺 outcome / outcome 越界 / tone 越界 / listened 越界 / aftermath 越界 / 未知子命令 / review 找不到 id / set 无字段）、层次推断三种（含显式覆盖）、healthy 数据集（risk 与 report 均 rc=0、报告落盘）、risky 数据集（risk 与 report 均 rc=1）、幂等覆盖、话术检索、版本一致性。
- 冒烟包含针对开发过程中修掉的真 bug 的回归断言：关系账户透支触发高风险、plan 行动与提示同源、话术库命中限制输出 3 套、层次推断可在记录层覆盖。

**评分：5.0 / 5**

## 总评

**T5 / R5 / A5 / C5 / E5 = 5.0 / 5**

与 #15–#17 同基准、同质量。这一版相对 #16/#17 的增量价值：① `plan`/`risk` 行动与提示同源（前序版本在 #16/#17 已修复，本版从首版就做对）；② 新增 `script` 子命令——从带出处的话术库按场景×目标检索，把「给建议」从主观经验升级为循证模板；③ 层次推断（事实/情绪/身份）是一个有理论支撑的原创量化点，对应沟通科学里最有解释力的「困难对话三层模型」。

待提升空间（如实标注）：层次推断是启发式，依赖用户自评的 tone/listened 字段，存在系统性偏差——文档已明确说明，并建议以 `aftermath`/`reaction` 等外部信号为准。
