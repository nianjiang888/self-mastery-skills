# self-focus-agent · FAQ

**Q1：这包和番茄钟 App 有什么区别？**
番茄钟解决「启动与节奏」，本包解决「看清什么打断你」。它记录实际专注、打断次数与来源，输出「干扰来源 Top」，把焦虑变成可消除的清单。两者可叠加用。

**Q2：退出码 4（长期警报）是不是说我懒？**
不是。分心是认知结构属性（Leroy 注意力残留、Rubinstein 切换税），不是道德缺陷。4 只是说「窗口内日均专注低于基线」，提示你该把深度块排进日历固定时段、物理隔离高频打断源。

**Q3：基线阈值（打断≥3、日均<90 分钟）能改吗？**
能。编辑 `resources/focus-baselines.json` 即可。这些是启发式，不是医学标准。例如你本就碎片化工时，可把 `longterm_alert_minutes` 调低。

**Q4：为什么 `plan` 时长不锁死 25 分钟？**
番茄钟 25 分钟对长程深度创造可能过短、频繁休息反而打断思路；对高度协作也不适配。所以 `plan --planned-minutes` 支持 25/50/90，尊重个体节奏。

**Q5：来源写「刷抖音」会归到哪？**
自动归一为「自己刷手机」（词典见 `focus-baselines.json`，含 微信/同事/电话/邮件/会议/环境噪音/自己走神 等）。归一后统计才干净，不会出现「刷抖音」「刷视频」「玩手机」各算一类的噪声。

**Q6：网络说注意力残留降低 17–25%、人注意力只有 8 秒，是真的吗？**
溯源后**找不到可靠出处**，本引擎不引用。我们只做可证伪的动作（减少悬挂的未完成任务数、减少打断次数），不编百分比。

**Q7：数据存在哪？**
默认 `.self-focus/`（可用 `--store` 指定）。`focus-log.jsonl` 是纯数据事件流，可随时重跑 `measure`/`report` 重新分析，不绑死任何工具。

**Q8：能嵌进自动化吗？**
能。`report` 退出码 0/1/4 可被脚本/CI 读取（如每日定时跑，非 0 即提醒）。`measure` 同理。
