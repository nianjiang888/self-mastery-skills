# 双重编码（Dual Coding）：用文字+图像给记忆上双保险

## 一、理论源流与权威文献

双重编码理论由 Allan Paivio 提出，主张人脑有**两个相对独立又相互连通的表征系统**：言语系统（处理语言、文字）与表象系统（处理图像、空间）。当信息同时以两种形式编码，记忆更牢、提取线索更多。权威文献：

- *Paivio, A. (1971). Imagery and Verbal Processes. Holt, Rinehart & Winston.* 双重编码理论的奠基专著。
- *Paivio, A. (1986). Mental Representations: A Dual Coding Approach. Oxford University Press.* 系统成熟表述，提出"言语+表象"双通道与"联想联结"机制。
- 与 Mayer 的多媒体学习（见 generative-learning）一脉相承：CTML 的"双通道"正是双重编码在教育技术上的延伸。

## 二、为什么"双通道"抗遗忘

关键在**冗余与互联**。一个只有文字编码的事实，如果文字线索失效就找不回；但若同时有一幅图，即使文字忘了，图像仍能触发回忆。Paivio 用"具体性效应"证明：具体、可成像的词（如"苹果"）比抽象词（如"正义"）更好记——因为具体词能同时激活言语与表象双通道。

更进一步，双系统之间有**联结**：看到图能唤起词，读到词能唤起图。这种双向线索让提取路径翻倍，直接对抗 Ebbinghaus 的遗忘（多一条路，就少一分丢）。

## 三、与本引擎的映射

- `ingest` 的 note 鼓励"用自己的话 + 画个图/表"，这就是主动双重编码；
- `interleave` 混合不同表征形式（文字概念、图像、案例）时，记忆线索更丰富；
- 配合生成学习的 drawing / mapping 策略（Fiorella & Mayer 2015），把"读"升级为"画"。
- 资源库 `learning-strategies.json` 中 dual-coding 条目即此理论的落地提示。

## 四、落地要点与误区

要点：把抽象概念强行"具象化"——给一个比喻、一幅草图、一张对比表；复习时既读文字也看图示。误区：认为"加图就一定好"——依据冗余效应（见 cognitive-load-theory），当图与文字完全重复且无关时反成噪音；图应提供文字没有的角度（如结构、关系），而非照搬。

## 五、可核验要点

- Paivio (1971) *Imagery and Verbal Processes*；Paivio (1986) *Mental Representations*。
- 双系统：言语 + 表象；双通道冗余提升保持。
- 具体性效应：可成像信息更好记。
- 用法：概念配图/表/比喻，增提取路径。

## 七、实战工作流示例

给"间隔效应"做双重编码，不只在 note 里写文字：

```
learn.py ingest --concept "间隔效应" \
  --note "文字：分散练习优于集中。图像：画一条'保持率vs时间'曲线，
          在膝部标出复习针脚（1/2/4/7/15天）"
learn.py elaborate --id <id> --relate "曲线图对应Ebbinghaus；针脚对应Leitner盒"
```

文字给定义，图像给"形状与节奏"，二者联结后，即使某天忘了文字，看到草图也能唤醒"哦是要隔几天复习"。这就是双通道冗余的价值。

## 八、常见问答深挖

问：所有概念都要配图吗？ 答：优先给"抽象、关系型"概念配图（如认知负荷三类、遗忘曲线、间隔节奏），具体名词（如"组块"）本就易成像，可不强行画图。重点是"文字没有的角度"，不是为画而画。

问：双重编码和生成学习矛盾吗？ 答：不矛盾，反而叠加。生成学习让你"画出来"（drawing 策略），双重编码解释"为什么画出来更牢"。self-learn-agent 鼓励在 ingest/elaborate 里图文并用，正是两理论合流。

问：看现成图算双重编码吗？ 答：弱。自己画/自己选图并标注，才同时激活言语（标注）与表象（构图）双通道；单纯扫一眼别人的图，表象通道参与浅，效果打折。

## 十一、理论速查卡

- 提出者：Allan Paivio（加拿大心理学家）。
- 核心年份：1971（*Imagery and Verbal Processes*）、1986（*Mental Representations*）。
- 一句话：人脑有言语、表象两个独立又连通的系统；双通道编码让记忆有冗余、提取多路径。
- 关键证据：具体可成像的词比抽象词好记（具体性效应）。
- 与 self-learn-agent：ingest 的 note 鼓励"文字+草图/表"，elaborate 用 relate 织语义网，二者都是双重编码的落地。
- 易错点：图若只是文字复读，触发冗余效应变噪音；图应提供文字没有的结构/关系视角。
- 最小行动：下次 ingest 一个抽象概念时，顺手画一张两行三列的对比表或一条流程草图。
- 关联理论：生成学习的 drawing 策略（Fiorella & Mayer 2015）、认知负荷的冗余效应（Sweller 1988）。
- 自检：我给这个概念配的图，是否提供了文字没有的新角度？若否，等于没编码。

> 结论：给知识"两条命"——一条文字的，一条图像的。双重编码告诉我们，会画一张草图的人，比只会抄定义的人记得牢一倍。self-learn-agent 鼓励在 `ingest` 与 `elaborate` 里图文并用，正是给记忆上双保险。
