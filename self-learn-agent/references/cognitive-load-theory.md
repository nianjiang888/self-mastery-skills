# 认知负荷理论（Cognitive Load Theory）：让有限的脑子用在刀刃上

## 一、理论源流与权威文献

认知负荷理论（CLT）由 John Sweller 于 1988 年提出，核心关切是：人的工作记忆容量极其有限，教学设计应当尽量减少"无谓消耗"，把稀缺的认知资源投向真正的图式建构。奠基文献：

- *Sweller, J. (1988). Cognitive Load During Problem Solving: Effects on Learning. Cognitive Science, 12(2), 257–285.* 首次系统阐述认知负荷与学习效率的关系。
- *Sweller, J., Ayres, P., & Kalyuga, S. (2011). Cognitive Load Theory. Springer.* 权威教科书，整合三十年进展。
- *Paas, F., Renkl, A., & Sweller, J. (2003). Cognitive Load Theory and Instructional Design. Educational Psychologist, 38(1), 1–4.* 面向教学设计的实用综述。

## 二、三类负荷

CLT 把负荷拆成三类：

1. **内在负荷（intrinsic）**：任务本身的复杂度，由元素间交互程度决定，无法消除只能管理（如学微积分天然比学加法费脑）。
2. **外在负荷（extraneous）**：由糟糕呈现方式制造的无谓消耗（如文字与图分开、无关装饰、冗长铺垫）。这是应当**竭力削减**的。
3. **关联负荷（germane）**：用于建构图式、深度加工的"好负荷"。应当**投资**而非节省。

总负荷 = 内在 + 外在 + 关联，不能超过工作记忆上限。好设计的本质是：砍外在、控内在、增关联。

## 三、经典效应：样例、专长逆转、冗余

- **样例效应（worked-example effect）**：初学者看"已解例题"比自己硬解题学得更快，因为省下了搜索解法的外在负荷。但注意——它只适用于新手。
- **专长逆转效应（expertise reversal effect）**：给专家看详细样例反而成负担（冗余外在负荷），专家需要的是精简、可迁移的提示。这提示 self-learn-agent 的 `ingest` 应按基础深浅调节信息密度。
- **冗余效应（redundancy effect）**：同时塞文字+语音念同一内容，反而比单一渠道更差——因为两通道在重复加工同一信息，浪费带宽。

## 四、对本引擎的直接启示

CLT 解释了为什么"照抄原文""一次性堆太多"会失效：`ingest` 要求 note 写"自己的话"（降低外在、增关联）；`interleave` 控制每次主题数量（控内在）；`elaborate` 与 `quiz` 把资源投向提取（关联负荷）。同时，CLT 提醒我们**不要无限加练习量**——当负荷超限，加量反而减效，所以 `review` 用间隔把总量摊薄，而不是每天狂刷。

## 五、落地误区

误区一：认为"负荷越低越好"。错，要砍的是外在负荷，关联负荷值得投。误区二：对专家用新手教法（详尽样例）——触发专长逆转。误区三：信息越多越安心——冗余效应下，多余信息只是噪音。

## 六、可核验要点

- Sweller (1988) *Cognitive Science 12(2):257–285*：CLT 奠基。
- 三类负荷：intrinsic / extraneous / germane。
- 样例效应、专长逆转效应、冗余效应。
- 设计原则：砍外在、控内在、投关联。

## 七、实战工作流示例

用 CLT 审视一次学习安排，把"外在负荷"砍到最低：

```
# 反例：边看视频边抄逐字稿边开十个网页 —— 外在负荷爆表
# 正例：先 ingest 用自己的话记核心，再 quiz 提取，再 elaborate 深加工
learn.py ingest --concept "样例效应" --note "新手看已解例题比硬解更省负荷"
learn.py quiz --id <id> --recall 0.8
learn.py elaborate --id <id> --relate "专长逆转：专家反而被详细样例拖累"
```

正例把资源投向关联负荷（图式建构），而非浪费在冗余抄写。每天练习总量由 `review` 间隔摊薄，避免单次负荷超限。

## 八、常见问答深挖

问：是不是负荷越低学习越好？ 答：错。要砍的是外在负荷，关联负荷值得投。完全无负荷=没在学。目标是"总负荷不超上限，且上限内尽量是关联负荷"。

问：专长逆转怎么落地到自学？ 答：当你对某个领域已熟，就减少"详尽笔记/例题"，改为"精炼提示+交错实战"。self-learn-agent 不自动判断你的水平，但你可用 `report` 看 mastery，高的点减少 ingest 细节、增加 interleave 迁移。

问：冗余效应对"图文并用"矛盾吗？ 答：不矛盾。双重编码的图应提供文字没有的角度（结构/关系），而非念同一句话；若图只是文字的复读，才触发冗余效应变成噪音。

## 十一、理论速查卡

- 提出者：John Sweller（澳大利亚教育心理学家）。
- 核心年份：1988（*Cognitive Science 12(2):257–285*）；教科书 2011（Springer）。
- 一句话：工作记忆容量有限，教学设计要砍外在负荷、控内在负荷、投关联负荷。
- 三类负荷：内在（任务本身）、外在（糟糕呈现）、关联（图式建构，值得投）。
- 关键效应：样例效应（新手看例题更省）、专长逆转（专家被详例拖累）、冗余效应（双通道复读变噪音）。
- 与 self-learn-agent：ingest 写自己的话降低外在；interleave 控每次主题数控内在；quiz/elaborate 投关联。
- 易错点：以为"负荷越低越好"——错，要砍的是外在，关联负荷该投。
- 最小行动：下次学习前问自己"这一安排里哪些是浪费带宽的外在负荷"，先砍掉再学。
- 关联理论：生成学习（Fiorella & Mayer 2015）、双重编码（Paivio 1986）。
- 自检：我今天的学习，关联负荷占比高吗？还是大半时间在抄写和划重点？

> 结论：脑子一次装不下太多，好学习不是"更努力地塞"，而是"更聪明地排"。认知负荷理论是 self-learn-agent 一切"少而精"设计（间隔而非狂刷、自己的话而非抄写）的底层理由。
