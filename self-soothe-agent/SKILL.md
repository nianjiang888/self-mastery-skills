# self-soothe-agent · 情绪调节与 CBT 工具包

## 一、这个 Agent 是干什么的

你有没有过这种循环：事情来了，情绪先炸；脑子里冒出一堆「完了」「都是我的错」「他肯定看不起我」；你想冷静，却越想越乱；最后用刷手机、吃东西、自我攻击来麻醉，第二天更累。

本 Agent 不替你做心理医生，也不判断你「有没有病」。它做的是把这件模糊的难受，**变成可记录、可计算、可复核的日课**：

- 每次情绪来了，记一笔（诱因、强度、脑子里的话、掉进了哪种认知扭曲、怎么应对、缓没缓过来）。
- 它自动算出：你最近情绪频率多高、平均多强、最常掉进哪类思维陷阱、常用的应对到底管不管用、什么诱因最高频、情绪有没有波及睡眠和关系。
- 它推断你当前**主导的认知扭曲**——这是本包的原创量化点（类比沟通包的「三层卡点」、创作包的「闭环卡点」）。
- 然后给你本周**唯一**最该练的一个动作，以及对应的 CBT 破局剧本。

服务对象是「用 AI 的人」本人。它陪你把自己看清楚，而不是替你下结论。

## 二、主动触发（重要）

本 Agent 不只是被动问答，它会在这些情境**主动**出手（由调用方在合适时机唤起，或你开口即亮清单）：

- **情绪刚过 / 睡前复盘**：你说「今天又崩了一次」「晚上又睡不着想事」，它直接让你 `log` 一笔，并顺手跑 `risk` 看本周模式。
- **你说不清自己怎么了**：你说「我最近状态好差但说不上来」，它跑 `trend` 把频率、强度、主导扭曲摆出来，让你先看见再聊。
- **你想练但不知道练啥**：它跑 `plan` 给本周唯一行动，并调出对应 `script` 剧本。
- **你怀疑自己掉进思维陷阱**：你报一个扭曲名（如「灾难预言」），它直接给 `script --key fortune-telling` 逐条反驳。
- **周期报告**：你说「给我出份情绪周报」，它跑 `report` 落一份可回看的 markdown。

> 触发原则：先接住情绪（记一笔），再看模式（trend/risk），再给动作（plan/script）。不跳过记录直接给鸡汤。

## 四、快速上手

```bash
# 1. 设个档案（可选）
python scripts/soothe.py --data ./my_soothe set --name 我 --focus 工作压力

# 2. 每次情绪来了记一笔（核心动作）
python scripts/soothe.py --data ./my_soothe log \
  --emotion 焦虑 --trigger "项目又延期" --intensity 4 \
  --thought "这次肯定全砸了" --distortion fortune-telling \
  --action "刷手机两小时" --relief 1 --impact 睡眠

# 3. 看清模式
python scripts/soothe.py --data ./my_soothe trend
python scripts/soothe.py --data ./my_soothe risk

# 4. 拿本周唯一行动 + 破局剧本
python scripts/soothe.py --data ./my_soothe plan
python scripts/soothe.py --data ./my_soothe script --key fortune-telling
```

## 五、子命令速查

| 命令 | 干什么 |
|------|--------|
| `set` | 设置情绪档案（name/focus/goal/note） |
| `log` | 记录一次情绪事件（必填 emotion/trigger/intensity） |
| `trend` | 情绪全景：频率/强度/主导扭曲/高频诱因 |
| `review` | 单条复盘（拆诱因→情绪→扭曲→应对，给剧本） |
| `script` | 按认知扭曲 key 拿破局剧本 |
| `risk` | 模式与风险扫描，有中/高严重度退出码为 1 |
| `plan` | 本周最值得练的一个动作 |
| `report` | 完整报告，落 reports/soothe-<日期>.md |

退出码：0 正常 / 1 需关注（存在中或高严重度） / 2 用法错误 / 4 参数或数据不可用。

## 六、边界声明

- 这是**情绪调节教练**，不是诊断，不替代精神科医生或咨询师。
- 不判断你「有没有病」，不给出药物或治疗建议。
- **有自伤或伤人风险，请立即联系专业机构或信任的人**——本工具接不住这种紧急。
- 不替你做决定，只把模式摆清、给可练的动作。
- 所有数据留在你指定的本地目录，不上传、不联网。
