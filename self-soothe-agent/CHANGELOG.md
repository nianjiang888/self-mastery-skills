# CHANGELOG · self-soothe-agent

## v2.0.0（首发深度版，2026-09-01）

### 能力
- 真引擎 `scripts/soothe.py`，8 子命令：set / log / trend / review / script / risk / plan / report。
- 情绪事件记录：诱因、情绪类型、强度(1-5)、自动思维、认知扭曲(11 类)、应对方式、缓解(0-5)、影响面(睡眠/关系/工作/身体/专注)。
- 指标：频率(件/周) / 平均强度 / 强度趋势 / 最常见情绪 / 主导认知扭曲及占比 / 应对有效性 / 高频诱因 / 影响面分布 / 最长平静天数。
- **原创量化点 `infer_distortion`（主导认知扭曲推断）**：优先级 情绪过载 > 高强波动 > 应对低效 > 主导扭曲清晰 > 均衡 > 健康；类比沟通「三层卡点」、创作「闭环卡点」。
- 认知破局剧本库（resources/soothe-scripts.json）：10 类扭曲 + 应对低效 + 情绪过载，每条带步骤/示例/避免/出处。
- 13 篇带出处的方法论长文（references/）。
- 实物证据：events.jsonl（幂等覆盖）+ profile.json + reports/soothe-<日期>.md。
- 退出码 0/1/2/4；中文报错；全中文包内、英文参数名。

### 写作原则
- references 自然成篇、带作者年份，不凑字数、不空喊口号。
- 边界诚实：非诊断、不替代医生/咨询师、有自伤/伤人风险引导专业机构、数据全本地无联网。

### 合规
- 不声称疗效；理论仅作为「可练动作」的来处；对存争议的比例（Fredrickson 3:1）只引用方向。
- 不触碰任何安全红线（无 http/https/IP、无绝对路径、无过严 injection）。
