# 反刍思维（Rumination） —— Nolen-Hoeksema 1991

Susan Nolen-Hoeksema 在 1991 年提出「反刍」（rumination）的概念，指**反复地、被动地想「我为什么这么糟、这感觉什么时候是个头」**，而不去解决任何事。她的系列研究（如 1991、2008 与 Watkins 的综述）给出了一个反直觉结论。

## 想得多 ≠ 想得透

直觉上，遭遇打击后多想想总能想明白。但 Nolen-Hoeksema 的实验显示：**反刍反而会延长并加深抑郁和焦虑**。因为反刍把注意力锁在「情绪本身」和「我有多惨」上，既不开出行动，也不带来新视角，只是把同一团情绪反复加热。

更扎心的是性别差异研究：女性比男性更倾向反刍，部分解释了为什么女性抑郁发病率更高。这不是「女性更脆弱」，而是应对风格的统计差异。

## 为什么夜里最危险

反刍常在「无事可做」时出现——睡前、独处、刷手机时。本工具的 `sleep_share` 指标专门点名「情绪波及睡眠」，背后机制正是反刍：你躺下后脑子自动回放白天的糟心事，越想越清醒。

## 如何打断

Nolen-Hoeksema 与 Watkins（2010）后来区分了「适应性反刍」（具体问题拆解、求解）与「病理性反刍」（反复沉浸情绪）。打断的关键是从「沉浸」切到「求解」或「转移」。本工具 `emotional-overlap` 的「睡前情绪截止线——把盘算写进次日清单」正是把反刍转化为具体待办，关掉大脑的循环播放。
