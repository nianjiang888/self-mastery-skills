#  broaden-and-build 理论 —— Fredrickson 2001

Barbara Fredrickson 在 2001 年提出积极情绪的 **broaden-and-build** 理论，发表于 *American Psychologist*。它解释了为什么「开心一下」不是浪费时间，而是情绪调节的隐形基建。

## 积极情绪拓宽思维-行动 repertory

Fredrickson 发现：消极情绪（怕、怒）会让人的注意力**窄化**——只盯着威胁，视野收缩（fight-or-flight 的生物学基础）。而积极情绪（愉悦、兴趣、宁静、爱）反而**拓宽**人的瞬间思维和行动范围：你更愿探索、更灵活、更能看到平时看不见的联系。

这就是「broaden」。而一次次被拓宽的瞬间，长期累积出「build」—— resilience（心理韧性）、社会关系、知识技能、身体资源。积极情绪不是消极情绪的「对立面药」，而是另起一条「攒家底」的线。

## 对情绪过载的直接启示

本工具的 `emotional-overlap` 剧本末尾那句「每天塞一件 broaden-build 小事（散步、好玩、和人笑）」，出处就在这里。当一个人被焦虑窄化时，强行「想开」很难；但去做一件微小有趣的事，能先把思维窗口撬开一点，情绪调节的余地才回来。

## 提醒

Fredrickson 后续研究（2005 与 Losada 的「3:1 临界点」）曾被方法学质疑，相关具体比例不宜当铁律。但「积极情绪有拓展与累积效应」这一核心机制，已被大量独立研究支持。本工具只引用其方向，不承诺具体比例。
