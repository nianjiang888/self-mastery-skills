# 模式识别与盲点探测方法论

self-reflect-agent 的核心价值不在「记一条日记」，而在「跨时间看清楚自己」。本文说明 `pattern` 与 `blindspot` 两个引擎背后的方法：如何从一堆离散记录里，提炼出可行动的「思维惯性」与「言行盲点」。

## 一、为什么需要跨时间，而不是单条复盘

单条反省容易陷入「这次是个意外 / 是对方的问题」。只有当同一模式在**不同日期**反复出现，才能排除偶然、确认惯性。因此引擎的 `pattern` 以「同一标签出现在 ≥ N 个不同日期」作为惯性判据（默认 N=2，可用 `--min-days` 调），而不是「出现总次数」。这为模式识别设定了「跨时间」的最低证据门槛。

## 二、标签从哪来：干净抽标的三条来源

模式识别的质量取决于标签质量。引擎用三条来源，避免中文按字切分产生噪声碎片：

1. **中文精选词库命中**：内置覆盖自我管理常见域的词表（拖延、熬夜、发火、逃避、专注、储蓄……），文本中出现即作为干净标签。
2. **拉丁词**：英文术语（procrastinate、anxiety 等）直接入标。
3. **显式标签**：调用方用 `--tags` 主动标注，最精准。

三者合并去重。这样 `pattern` 看到的始终是「拖延」「发火」这类语义完整、可跨日比对的单位，而非「目延」「期我」之类的字符碎片。

## 三、惯性检测算法

```
对每个标签 t:
    统计出现 t 的不同日期数 days_seen
    统计 t 的总出现次数 total
若 days_seen >= 阈值:
    记入「惯性」列表，按 (days_seen 降序, total 降序) 排序
```

同时统计情绪分布（按 `emotion` 字段聚合），输出情绪基调。若日志中出现破坏性线索（发火 / 逃避 / 拖延 / 冲动消费等），单独计 `destructive_hits` 并预警——这类惯性往往是单环学习改不掉的根因信号。

**退出码约定**：存在跨天数 ≥3 的破坏性惯性 → 退出 `1`（需关注）；否则 `0`。

## 四、盲点探测：Brookfield「现实透镜」的自动化

人最不可信的是「对自己的叙述」。盲点探测把两件事并排比对：

- **claim（自称）**：你用 `claim --kind value` 登记「我重视什么」，或用 `--kind avoid` 登记「我想改掉什么」。
- **日志事实**：所有 `log` 条目的全文与标签。

判定规则：

| claim 类型 | 日志中是否命中 | 结论 |
|---|---|---|
| value（重视） | 未命中 | 言行 gap：自称重视却无实践 |
| avoid（想改） | 命中 | 反复失守：想改却仍在做 |

任一命中即记为盲点。**多条盲点（≥2）意味着「自我叙事」与「实际行为」系统性背离**，引擎退出 `4（双环警报）`——此时正确的应对不是「下次注意」，而是追问背后前提（为什么重视却不做 / 为什么想改却改不掉）。

## 五、降低误报与疲劳

- **阈值过滤**：惯性必须跨 ≥2 天才记，过滤单次偶发。
- **claim 去重**：重复登记同一条 claim 自动跳过，避免盲点重复计数。
- **可解释**：每个模式 / 盲点都给出「出现天数 / 命中证据」，不黑箱判定，使用者可复核。
- **可重跑**：`reflect-log.jsonl` 与 `claims.json` 是纯数据，任何时刻重跑 `pattern` / `blindspot` 都得到一致结论，便于长期追踪。

## 六、局限与诚实边界

- 情绪为「未标注」时，引擎靠词表自动识别；自由文本的情绪识别天然不完美，重要反省请用 `--emotion` 显式标注。
- 词库覆盖有限，生僻表达可能漏标；配合 `--tags` 可补足。
- 盲点判定基于字符串命中，若 claim 文本与日志用词完全不同义但同义，可能漏报。这是机制的可解释代价，换来了「不臆测」的诚实。
