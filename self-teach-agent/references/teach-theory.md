# 自我教学的理论根基（teach-theory）

self-teach-agent 不是"再写个笔记工具"那么简单。它的每一环都对应一条经过验证的学习科学或机器学习结论。本文把四条主线讲透：**Self-Instruct（模型教自己）、STaR（只留对的）、Curriculum Learning（由易到难）、遗忘曲线与间隔重复（学了别忘）**。读完你会明白，为什么"自己教自己"不是玄学，而是一套可工程化的闭环。

---

## 一、Self-Instruct：模型是怎么"教自己"的

### 1.1 问题从哪来
指令微调（instruction tuning）让模型学会"听懂人话"，但成功极度依赖**高质量人工指令数据**。这有三道坎：贵（人工标注要钱要时间）、窄（标注者爱写常见 NLP 任务，长尾创意需求覆盖不到）、有壁垒（好数据集往往私有）。Self-Instruct（Wang et al., 2022, arXiv 2212.10560）想的是：能不能让模型**自己生成训练数据**，bootstrap 出自己的课程？

### 1.2 四步管线
1. **指令生成**：从 175 个人工种子任务里采样 8 个（6 人工 + 2 模型生成）当上下文，让 GPT-3 brainstorm 出新的、不同的指令。
2. **任务分类**：用 few-shot 判断这是"分类型"（输出空间有限）还是"生成型"，因为两类实例化策略不同。
3. **实例生成**：
   - 生成型用 **Input-First**：先造输入，再给输出；
   - 分类型用 **Output-First**：先定标签，再围绕标签造平衡的输入，避免标签偏置。
4. **过滤**：ROUGE-L 相似度 > 0.7 的与已有指令去重；含"图片/图表"等文本模型处理不了的词的直接剔除；重复的实例与冲突的输入输出对删除。

### 1.3 结果有多硬
- 用这套合成数据微调 vanilla GPT-3，在 Super-NaturalInstructions 上 **+33% 绝对提升**；
- 在人工写的"新任务"评测上，逼近用私有数据+人工标注训的 InstructGPT-001，只差 5%；
- 规模：从 175 个种子，生成了 **52,445 条指令、82,000+ 实例**。

### 1.4 关键洞见（self-teach 直接继承）
Self-Instruct 证明了一件事：**模型能教自己它已经"潜在会"但执行不稳的能力**。换句话说，学习很多时候不是"从无到有"，而是"把已有但不可靠的能力固化下来"。这也是 self-teach 把"摄入→结构化→自测→晋升"做成闭环的哲学来源——你读到的东西，大概率不是全新知识，而是需要被你"激活并固化"的潜在能力。

### 1.5 它的坑（self-teach 怎么补）
Self-Instruct 的过滤是**启发式**的：看重复、看流畅、看能不能处理，但**不验证答案对不对**。于是模型若自信地生成错误答案，也会被收进训练集，放大幻觉。这个坑，由下一位主角 STaR 来补。

## 二、STaR：只保留"对的"

STaR（Self-Taught Reasoner, 2022）面对的是推理任务。它的循环是：
1. 对每个问题，让模型生成**推理链 + 答案**；
2. **只保留最终答案与标准答案一致的**推理链；
3. 用这些"正确推理"微调模型。

一句话点破：**self-training 要把"不可靠的能力"变成"可靠的"——过滤按正确性，不按流畅度**。Self-Instruct 卡在"像不像对的"，STaR 卡在"是不是真的对"。

self-teach 的"晋升门禁"就是 STaR 这一刀的工程化：一个知识单元，不是"读过/写过"就算掌握，而是**四要素齐全（concept/definition/why/example）且能回忆（评分≥4）**才允许晋升为可复用本领。否则物理拦下。这杜绝了 Self-Instruct 式的"虚假掌握"——读了≠会了。

## 三、Curriculum Learning：由易到难不是偷懒

### 3.1 形式化
Bengio et al. (2009, ICML) 把"先易后难"写成：训练分布是一串 `p1, p2, ..., pT`，满足支持集和熵随 t 增大，最终 `pT` 逼近均匀分布。每一步优化加权风险 `Lt(θ)=Σ pt(i)·ℓ(θ;xi,yi)`。两样东西定死一个课程：**难度度量 d** 和 **pacing 函数 g**（多快放更难样本）。

### 3.2 两条直觉
- **优化视角**：从简单版本的任务起步，相当于在一个更平滑的损失曲面 surrogate 上起手，SGD 更容易落到好 basin。这跟数值优化里的 continuation method（同伦延拓）是同一回事。
- **统计视角**：有限数据和有限时间内，先喂干净/简单的样本，等于隐式正则化，把容量先分配给稳健模式，而不是一上来就记噪声。

### 3.3 难度怎么定
外部度量（句子长度、图像分辨率、任务启发式）或**学习型度量**（当前 loss 高=难，或教师模型给的低置信=难）。一个坑：基于 loss 的难度会随训练共演化——初始化时难的样本，几轮后可能变简单，所以现代做法要**周期性重算难度**，或用分位数代替固定阈值。

### 3.4 衍生家族
- **self-paced learning**（Kumar et al., 2010）：模型自己决定吃哪些样本，用正则把"包含质量"随时间往上拉；
- **competence-based curriculum**：按当前能力门槛渐进放量；
- **automatic curriculum learning**：用 bandit / RL / 元学习去发现课程，老师策略因学生验证损失下降而受奖励，能发现人直觉想不到的非单调课程。

self-teach 的 `curriculum.py` 实现的是最经典也最稳妥的那一版：先修图拓扑排序保证合法，再在同层可选节点里按难度升序——既尊重知识依赖，又贯彻"由易到难"。它刻意不追求全自动课程发现（那需要训练回路），而是给你一个**可审阅、可调整**的排课，避免"坏课程反而拖慢学习"（Bengio 原话：糟糕的课程甚至可能有害）。

## 四、遗忘曲线与间隔重复：学了别忘

### 4.1 艾宾浩斯遗忘曲线
1885 年 Ebbinghaus 用无意义音节自我实验，发现记忆保留率随时间指数衰减：**R = e^(-t/S)**，R 是保留率，t 是时间，S 是记忆稳定性。不复习，约一天后就剩 33%，一个月后所剩无几。这不是"你记性差"，是大脑的物理属性——它是为"用进废退、释放空间"设计的，不是为"永久存档"设计的。

### 4.2 两条反制证据
- **测试效应（testing effect）**：主动回忆比反复阅读留存高得多。读十遍不如遮住答案想一遍。
- **间隔效应（spacing effect）**：把复习分散在多个时间点，比考前突击一次有效得多。

### 4.3 SM-2：把间隔变成算法
SuperMemo 在 1987 年给出的 SM-2 算法，是间隔重复的事实标准，也是 self-teach `retention.py` 的内核：
- 每个单元维护 **易度因子 ease**（默认 2.5）、**间隔 interval**、**重复次数 reps**；
- 每次回忆评分 grade（0-5）；
- grade < 3：失败，重置（明天重来）；
- grade ≥ 3：间隔按 ease 拉长（第1次1天、第2次6天、之后 interval×ease）；
- ease 随评分微调，但设下限 1.3，避免塌缩。

由此得到一条"下次复习日"，并可由 interval 反推稳定性 S，随时算"现在还记得多少"。self-teach 把这条曲线做成了可读数——你不再是"感觉该复习了"，而是看到"保留率已跌到 55%，该召回了"。

## 五、四条线如何拼成 self-teach

| 环节 | 对应理论 | 在包里的落点 |
|---|---|---|
| 摄入材料 → 拆单元 | Self-Instruct 的"生成/实例化"精神 | `teach.py --ingest` |
| 由易到难排计划 | Curriculum Learning | `curriculum.py` |
| 自测"真掌握了吗" | STaR 的"只留对的" + 测试效应 | `teach.py --quiz/--promote` |
| 学了别忘 | 遗忘曲线 + SM-2 | `retention.py` |
| 固化成能力 | Self-Instruct 的"微调原模型" | `--promote` 晋升 + 衔接 self-improvement |

它们共用一个底层信念：**学习必须闭环且有证据**。没有结构化，读了就散；没有排课，无从下手；没有自测，虚假掌握；没有复现，学了就忘。self-teach 把这四个"没有"一个个堵上，并且每一步都落进日志、可被检验——这正是一个 4.7 分级别技能该有的样子：理论硬、闭环完整、不靠人记。
