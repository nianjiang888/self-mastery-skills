# 实物期权与灵活性价值（Dixit & Pindyck）

## 出处与核心思想

Avinash Dixit 与 Robert Pindyck 在 **1994 年《Investment Under Uncertainty》** 中把金融期权的思想引入实物投资决策。核心洞见：**在不确定性高、不可逆成本大的世界里，「推迟」「分阶段」「保留退出权」本身就是一种资产，可以被估值**。

传统净现值（NPV）把投资当成「现在做或不做」的开关，忽略了「等一等、看清楚再决定」的价值。实物期权框架纠正这一点：当你拥有「未来某时按某价行权」的权利而非义务时，不确定性的上升**提高**了这份期权的价值——因为坏结果你可以不行权（止损），好结果你才行权（获利）。

## 三个可操作的启示

1. **把不可逆投入当行权价**：每一次 All-in 都是「行权」，代价是放弃未来所有其他选项。单向门决策尤其要算清这笔账。
2. **高不确定性下，小占位优于大赌注**：宁可花小钱占个坑（买期权），保留放大或退出的权利，也不要一次性赌死。
3. **设计阶段门（stage gates）**：把大决策拆成若干可逆的小阶段，每阶段只押最小成本，根据涌现信息决定是否进入下一阶段。

## 与单向门框架的咬合

Bezos 可逆性框架（见 `reversible-framework.md`）告诉我们要区分单向门/双向门；实物期权则进一步说：**面对单向门，先别急着走进去，看看能不能「买张门票」而不是「买断整栋」**。它把「灵活性」从模糊的形容词变成可权衡的变量——在 `decide.py` 的框架库里，`real_options` 与 `bezos_doors` 被显式关联：单向门前，先问能不能把不可逆拆成可逆的阶段。

## 边界

- 实物期权不是「永远拖延」的借口；当先发优势（first-mover advantage）或时机窗口明确时，过早等待也是成本。
- 它需要真实的「退出权」设计——若看似可退实则被合同/声誉锁死，期权就是幻觉。

## 引擎如何落地

`frameworks` 子命令收录 `real_options`，列出步骤与出处，并直接链接到 `bezos_doors` 框架。当面临「现在 All-in 还是先占个小位」的两难时，调出这个框架，把「保留灵活性的价值」显式放进决策权衡。它补足了本包的另一维度：后悔最小化看「长期情感」、Cynefin 看「因果可不可知」、实物期权看「不确定下的选择权估值」——三者共同构成「该不该、该多快、该留多少余地」的答案。
