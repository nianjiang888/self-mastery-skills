# FAQ · self-decide-agent

**Q1：这个包是给我做决定的 AI 吗？**
不是「替你选」的 AI。它是一套**强制调用 System 2 的外部脚手架**：把决策过程变成可记录、可回放、可复盘的数据，让你自己的判断更经得起检验。最终门往哪边开，仍是你定。

**Q2：偏差检测准吗？会不会误报？**
偏差检测是**确定性子串命中**（看文本里有没有关键词），所以不会「瞎猜」——只有文本真出现关键词才标记，绝不臆测。代价是覆盖面受 `resources/biases.json` 词表限制，生僻表达会漏检。`bias` 报告本身也明确写「未发现反复偏差 ≠ 决策一定理性」。

**Q3：后悔度怎么来的？引擎测我心理吗？**
不测心理。后悔度是**你自评输入**（0-100），引擎只负责结构化与跨决策追踪。缺省 `regret = 100 - score` 是工程近似（已在代码与文档标注取舍），重要决策建议用 `--regret` 显式给。

**Q4：可逆性谁来判断？**
你来判断。`log` 强制你填 `reversible` 或 `irreversible`，但「什么叫不可逆」由你定义；引擎只记录，并在 `replay` 时比对是否误判，算出「误判率」。这避免了引擎越权替你做价值排序。

**Q5：退出码 0/1/4 代表什么？**
`0` 正常；`1` 发现反复偏差 / 可逆性误判率偏高 / 单次重大不可逆误判；`4` 重大不可逆误判 ≥2 次（不可逆决策多次严重踩雷，系统性判断缺陷警报）。分级告警，不滥用最高级。

**Q6：数据存在哪？会联网吗？**
全部留在你指定的 `--store`（默认 `.self-decide`），纯本地 jsonl + markdown，**不联网、不收集任何外部数据**。

**Q7：文件好多（20 个），从哪看起？**
先读 `SKILL.md` 与 `README.md`；理论想深究看 `references/` 下 10 篇（每篇对应一个框架/理论，带出处）；想直接上手就跑 `frameworks` 挑框架、再 `premortem` 或 `log`。

**Q8：和 self-evaluate / self-reflect / self-protect 啥区别？**
- evaluate（#2）：评「物」——单条产出打分闭环。
- reflect（#8）：省「己」——跨时间模式与盲点。
- protect（#7）：挡「险」——动手前红线闸门。
- decide（本包）：管「择」——做选择本身，并把选择变成可复盘数据。四者不重叠。
