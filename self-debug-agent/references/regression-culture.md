# 回归文化：让每个 bug 变成永久抗体

调试的最高境界不是"这次修好了"，而是"**这个 bug 永远不会再犯第二次**"。实现它的唯一可靠手段，是**把每个 bug 落成一条永久回归测试**。本文件讲清楚这件事为什么是 self-debug-agent「自我」闭环里最锋利的一刀，以及怎么把它做对。

## 一、bug 的两种死法

一个 bug 被修掉后，有两种结局：

- **临时性死亡**：你改了一行，跑通了，关掉工单。三个月后，有人重构碰了那块逻辑，bug 悄悄复活。没人记得它，因为它没留下任何痕迹。这是大多数团队的常态，也是"怎么又踩同一个坑"的根源。
- **永久性免疫**：你修掉它的同时，写下一条**钉死正确行为**的测试。未来任何代码改动只要重新触发这个 bug，测试立刻变红，把复活扼杀在提交之前。

self-debug-agent 的 `--regress` 干的就是后者：每次治愈循环收敛后，强制你把这个 bug 翻译成一条确定性回归测试。久而久之，你的代码库长出一堵**回归墙**——每一块砖都是一个曾经咬过你的坑，现在都变成了哨兵。

## 二、为什么"记下来"比"修好"更值钱

认知科学里有个现象：人会从单次经验里过度自信地归纳，但遗忘速度也快。没有外部记忆，同一个坑踩第二次只是时间问题。回归测试就是**把脆弱的人类记忆外化成可执行、可重跑的机器记忆**。

这恰好对应同系列 `self-improvement-agent` 的"错误→永久记忆"棘轮：self-improvement 把错误变成抽象经验写进记忆文件；self-debug-agent 把错误变成**具体、可执行、会被每次 CI 自动跑**的测试。后者是前者在工程上的硬落地——经验不再是一段可能被忽略的文字，而是一行会吵醒你的 `assert`。

从复利角度看：每加一条回归测试，整个系统对"这一类错误"的免疫力就 +1，且永久累积。调得越多，系统越稳。这正是「自我进化」在工程层面的真义——不是某个时刻变聪明，而是每次跌倒都留下不让再跌倒的结构。

## 三、一条好的回归测试长什么样

回归测试质量决定了"墙"是盔甲还是摆设。原则：

1. **确定性**：固定输入 → 固定期望。禁止随机、时间戳、`uuid`、`time.sleep`、真实网络/数据库依赖。用本地固定数据或 mock。self-debug-agent 的 `--regress` 会主动拒绝含脆弱特征的条目（退出码 1）。
2. **钉住"正确行为"而非"当前行为"**：测试要断言 bug 修复后的**正确**结果，而不是"现在返回什么就断言什么"。否则你是在把 bug 合法化。
3. **最小且聚焦**：一条测试只覆盖这一个 bug 的触发条件与期望，别顺手塞一堆无关断言——出问题时你才能立刻知道是哪块逻辑回归了。
4. **命名即文档**：测试名直接描述被防御的 bug，如 `test_regress_empty_list_division`。扫一眼回归墙就知道系统扛过哪些坑。
5. **可独立运行**：不依赖测试顺序、不依赖共享可变状态，否则会出现"单独跑过、一起跑挂"的假象。

`--regress` 生成的脚手架已经把命名、bug 描述、输入、期望结构化记录进 `regression_log.jsonl`，你只需补完 `result == expected` 那一行，再落到正式测试套件里。

## 四、回归墙怎么用出价值

光写不跑，墙是装饰。要让它真起作用：

- **进 CI**：回归测试必须接进持续集成，每次提交/合并自动跑。红 = 有人复活了旧 bug，立刻拦下。
- **定期读墙**：self-debug-agent 的 `--report` 会把 `regression_log.jsonl` 列成墙。周期性扫一眼，你能看出自己常在哪类 bug 上反复栽（比如全是空值处理）→ 这是 `self-reflect-agent` 做洞察日志的绝佳原料。
- **用墙指导重构**：要动某块逻辑前，先看有没有回归测试罩着它。没有，先补一条再动——这才是"安全重构"的真实含义，而不是凭勇气。
- **让墙反哺分类**：连续第二次同类 bug，说明这一类防御还不够厚。回头加厚 taxonomy、加厚该类回归，而不是又手动修一遍。

## 五、和"自我"闭环的咬合

self-debug-agent 的完整闭环是：**复现 → 归类 → 治愈 → 验证 → 回归**。前五步是"这一次修好"，最后一步"回归"是"以后不再犯"。少了最后一步，你只是在做一次性灭火；有了它，你是在给系统接种。

把这套闭环和同系列产品拼起来，会看到一条完整的自我进化链：

- `self-evaluate-agent`：评估产出质量，告诉你差在哪；
- `self-debug-agent`：把差的地方（正确性）补上，并接种免疫；
- `self-improvement-agent`：把补过的经验变成永久记忆；
- `self-reflect-agent`：从回归墙与记忆里提炼"我常在哪跌"的元洞察。

一句话：**bug 不可怕，可怕的是 bug 没留下痕迹。让每个 bug 变成永久抗体，系统才会真的越调越稳。**
