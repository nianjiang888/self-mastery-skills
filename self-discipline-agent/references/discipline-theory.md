# self-discipline-agent 理论根基

自律的本质，不是「意志更强」，而是「把对的事变成不靠意志也能发生、把错的事变成需要额外努力才能发生」。本引擎把这一思想落成可核查的机制。以下七条研究传统，逐条对应引擎的一个位置。

## 一、承诺装置 Commitment Device（Thaler & Sunstein, 2008）

《Nudge》提出的「助推」框架里，承诺装置指**预先把自己的选择空间收窄**，让未来的自己更难选错。例如把储蓄设为工资自动划转（默认选项），比「每月记得存」可靠得多。引擎的 `commit` 强制你写下 `--stake`（违约后果）与 `--partner`（监督人），正是把抽象决心具象成装置；`audit` 的违约检测则让装置「真的会触发后果」而非形同虚设。

## 二、预承诺 Precommitment（Schelling, 1960）

博弈论学者 Thomas Schelling 在《The Strategy of Conflict》里指出：人有时会**主动放弃部分未来自由**，以约束那个「会被诱惑的自己」。 Odysseus 让水手把自己绑在桅杆上躲过塞壬，就是古典预承诺。引擎的 `--deadline` + 打卡 + 违约判定，正是数字化的「把自己绑起来」：到期未见打卡，系统即标记违约，不给你辩解余地。

## 三、实施意图 Implementation Intentions（Gollwitzer, 1999）

Peter Gollwitzer 的经典发现：光有「目标」不够，写成 **if-then 预案**（「如果 X 发生，那么我做 Y」）能显著提升达成率，因为把决策从「临场靠意志」提前到了「事前定规则」。引擎 `resources/commitment-prompts.json` 内置 if-then 模板，引导你把模糊的「我要自律」改写成可触发的动作。

## 四、自我损耗 Ego Depletion（Baumeister, 1998）—— 须诚实标注争议

Baumeister 提出「意志像肌肉会耗尽」的自我损耗模型，长期是自律领域的基石。但 **2016 年后多项大样本预注册研究（如 Hagger et al. 2016 的复现项目）未能复现该效应**，学界共识已动摇。本引擎因此**不把「靠意志硬扛」作为主策略**，转而强调外部承诺装置——这反而与「意志可能有限」的警示一致：别依赖一个会耗尽、且证据存疑的东西。诚实标注争议，是对用户的负责。

## 五、习惯回路（Duhigg, 2012）

Charles Duhigg 在《习惯的力量》中拆解习惯为 **线索—渴求—反应—奖赏** 四环。承诺装置对应「线索/反应」的重新设计：用押金（线索）和打卡（反应）替代旧的冲动反应。引擎按 `--category` 归类承诺，正是为了在 `audit` 里暴露「哪类线索最容易让你破功」，从而针对性改造该回路。

## 六、助推的透明原则（Sunstein, 2014）

Sunstein 后续强调，好的助推应**可退出、透明、服务于用户自身目标**，而非操控。本引擎所有后果由用户自己设定（`--stake` 自己填），监督人自己选，不替你做主——这是「帮你守住自己的承诺」，不是「替别人管你」。

## 串起来：从「靠意志」到「靠机制」

```
commit（登记+装置：后果/监督人/类别）
  → checkin（到期前履约打卡）
  → audit（到期未打卡=违约，按类别暴露最易破类型）
  → streak（连续履约的正反馈）
  → report（履约率单调不降的趋势）
```

每一条理论都对应一个子命令或一份产物。自律不再是格言，而是一套「设计好就会自己运转」的机制。
