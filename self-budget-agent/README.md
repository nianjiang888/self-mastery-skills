# self-budget-agent 使用说明

个人记账与存钱 AI Agent。**30 秒上手，之后每月花 5 分钟。**

## 30 秒上手

```bash
# 1) 建档案
python scripts/budget.py --data ./my_money set --income 12000 --emergency_fund 8000

# 2) 记一笔
python scripts/budget.py --data ./my_money log --date 2026-09-01 --kind out --amount 38 --category 餐饮

# 3) 看全景
python scripts/budget.py --data ./my_money trend --days 30

# 4) 本周只改一个
python scripts/budget.py --data ./my_money plan --days 30
```

要求：Python 3.8+，**零第三方依赖**（纯标准库）。

## 建议的使用节奏

| 阶段 | 做什么 | 为什么 |
|---|---|---|
| 第 1 个月 | 只 `log`，不判断、不设目标 | 记账的作用是恢复觉知，不是审判。一上来就设严格预算，通常两周内放弃 |
| 第 2 个月初 | 跑一次 `report`，看全景 | 用真实数据建立你自己的参考点，而不是被商家或同侪植入的锚 |
| 第 2 个月 | `set` 设目标储蓄率与分类预算 | 目标用**百分比**不用绝对金额——百分比天然抵抗生活方式膨胀 |
| 之后每月 | `trend` 对照 + `plan` 取一个行动 | 每次只改一个变量，否则不知道什么起了作用 |

## 子命令速查

| 命令 | 作用 | 关键参数 |
|---|---|---|
| `set` | 设收入/目标储蓄率/应急金/分类预算 | --income --target_save_rate --emergency_fund --emergency_months --cat_budget |
| `log` | 记一笔收支 | --date --kind(in\|out) --amount --category --note --id |
| `trend` | 收支趋势与结构 | --days（默认 30） |
| `budget` | 预算执行与 50/30/20 对照 | --days（默认 30） |
| `risk` | 财务风险与弱项扫描 | --days（默认 30） |
| `plan` | 本周最该做的一个改变 | --days（默认 30） |
| `report` | 完整报告（落盘） | --days（默认 30） |

`--data` 是**顶层参数**，必须放在子命令之前：

```bash
python scripts/budget.py --data ./my_money trend --days 30   # 对
python scripts/budget.py trend --days 30 --data ./my_money   # 错
```

## 关键指标口径

| 指标 | 算法 | 怎么看 |
|---|---|---|
| 储蓄率 | （收入 − 支出）÷ 收入 | <10% 触发中风险；比收入更能决定财务进度 |
| 折算月支出 | 窗口支出 ÷（天数 ÷ 30） | 应急金与 FIRE 目标线的输入 |
| 固定支出占比 | 房租/房贷/物业/水电/燃气/保险/贷款/学费/通讯/订阅 ÷ 总支出 | >50% 结构偏刚性 |
| 应急金覆盖 | 应急金余额 ÷ 折算月支出 | <1 个月触发高风险 |
| 分类预算执行 | 实际 ÷（月预算 × 窗口月数） | 正数即超支百分比 |
| 日支出波动 | 日支出标准差 ÷ 均值（变异系数） | >0.8 提示有冲动消费 |

「必需」与「想要」两个分类集合**互斥**（订阅归"想要"但计入固定支出），所以两者相加不超过 100%。未归类的支出保守计入「必需」。

## 退出码

| 码 | 含义 | 谁在用 |
|---|---|---|
| `0` | 正常，或仅有低严重度提醒 | — |
| `1` | 存在中或高严重度弱项 | agent 看到 1 就该主动介入 |
| `2` | 用法错误（缺子命令、参数不合法） | — |
| `4` | 参数或数据不可用（金额非正数、预算格式错） | — |

## 边界声明

- **前哨工具**，不是理财顾问。量化现金流与结构，不做诊断。
- **不做投资建议、不做税务与法律意见、不推荐任何产品。** 涉及资产配置、退休规划、债务重组、税务处理，请咨询持牌顾问。
- 指标全部从你的记录推出，**数据质量决定结论质量**。记录条数太少时不要对数字过度解读。
- 分类预算按月度设定，引擎按窗口天数折算对比。
- 数据全部存在本地，不联网、不上传。
