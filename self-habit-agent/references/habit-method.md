# 习惯叠加的实操方法（self-habit-agent）

> 理论讲完，本篇给可执行的步骤：如何用本引擎把「想养成的习惯」真正养住。所有产物都可重跑、可复核（4.8 基准：jsonl 事件日志 + markdown 报告）。

## 一、定义一条好习惯的四步法

不要用「我要更自律」这种无解句。用引擎的 `define` 把习惯拆成可机器识别的三件套：

1. **锚点行为（已稳定发生的事）**：起床刷牙、午饭后、关电脑、洗完澡。越具体越好。
2. **新行为（想接上的事）**：读 2 页书、喝一杯水、做 2 个深蹲。
3. **提示线索（外显信号）**：把书放书桌上、冰箱贴便利贴。

命令：

```bash
python scripts/habit.py define \
  --name 晨读 \
  --anchor "起床刷牙" \
  --behavior "读2页书" \
  --cue "把书摊开在书桌上"
```

引擎会回显叠加公式与默认的 66 天养成目标。同名再 `define` 会更新既有习惯而非新建。

> 常见错误：锚点写成「有空时」「下班后」——太模糊，会塌。锚点必须是每天几乎必然发生、且地点固定的动作。

## 二、每日打卡与去重

每天做完新行为，用 `checkin` 记录。支持按 `--name` 或 `--id` 指定；`--date` 可回溯补卡，`--today` 可覆盖「今天」用于测试或跨时区。同一天重复打卡会被自动跳过，不污染连击。

```bash
python scripts/habit.py checkin --name 晨读 --date 2026-03-10
```

连击的计算规则（确定性、可复核）：

- 日期连续 +1 天；同日重复忽略；隔天断签连击清零，但最长连击保留。
- **当前连击**仅在「最近一次打卡是今天或昨天」时才算存活，否则归零——避免你三天前打卡、今天看到「连击 1」产生虚假满足。

## 三、连击与中断怎么读

```bash
python scripts/habit.py streak     # 当前/最长连击
python scripts/habit.py lapse      # 断签天数与警报
```

退出码设计（对齐 self 系列 0/1/4 约定）：

| 命令 | 退出码 | 含义 |
|---|---|---|
| streak | 0 | 所有习惯均未中断 |
| streak | 1 | 有习惯已中断（断签≥1 天），需关注 |
| lapse  | 0 | 未断签 |
| lapse  | 1 | 中断（断签 1–6 天）|
| lapse  | 4 | 长期未养成（连续断签 ≥7 天），警报 |

`lapse` 的阈值（停滞 3 天、警报 7 天）写在引擎常量里，可按需调整，但逻辑上对「偶尔漏一天」与「系统性崩掉」做了区分——呼应理论篇「断一天≠全废」。

## 四、周期报告与行动建议

```bash
python scripts/habit.py report
```

报告落到 `habit-report.md`（实物证据），含三部分：

1. **逐习惯进度**：叠加公式、当前/最长连击、目标、进度%、断签天数。
2. **最稳 / 最易断**：跨习惯比较，帮你把精力放在最易断的那条上（帕累托：守住一条胜过新增三条）。
3. **下一步建议**：按状态分流——
   - 已养成 → 自动化阶段，降低监控频率；
   - 中断 → 今天补一次接回，别等周一；
   - 长期未养成 → 降到 1 分钟微习惯重启。

## 五、把引擎嵌进日常（主动触发）

self-habit-agent 是**能主动干活**的 agent，不是等你问的说明书。建议在以下情形主动启动：

- 用户说「我想养成……」「又没坚持住……」「坚持了 X 天」→ 主动 `define` / `checkin` / `report`。
- 每日固定时段（如睡前）主动跑 `report`，把进度推给用户。
- 检测到用户连续多日未打卡（结合外部信号）→ 主动 `lapse` 并给重启建议。

## 六、与同系列其他包的关系

- **self-discipline（#9）**：管「这条承诺算数不算数」，有期限、后果、监督人，偏单次大额约束。
- **self-habit（本包 #10）**：管「日日做的小事」，偏长线自动化，没有后果惩罚，只有连击与进度。
- **self-focus（#11）**：管「做的时候不分心」，与习惯互补——习惯让你开始，专注让你做深。
- **self-reflect（#8）**：定期回看「我的习惯模式是什么」，把习惯数据升维成自我洞察。

四者互不打架：discipline 守边界、habit 养轨道、focus 保深度、reflect 看全局。

## 七、诚实的局限

- streak 只记录「你打了卡」，不验证「你真的做了」。要防作弊，需接入客观信号（如运动手环、阅读 APP 数据），本引擎不伪造验证。
- 养成天数 66 是参考，不是 KPI。进度条到 100% 只代表达到中位养成窗口，不代表永远自动化。
- 习惯叠加对「情境稳定」的人最有效；生活高度不规律者，应优先用更稳定的锚点（如「上床放下手机」而非「通勤时」）。
