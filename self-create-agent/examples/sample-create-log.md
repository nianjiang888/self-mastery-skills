# self-create-agent 端到端示例

> 一个网文作者的真实一周。所有命令均用 `python scripts/create.py --data ./demo` 跑通，输出为引擎实际产物（精简展示）。

## 1. 设档案

```
$ python scripts/create.py --data ./demo set --name 年爷 --domain 写作 --focus 网文
已更新创作档案：{"name": "年爷", "domain": "写作", "focus": "网文"}
```

## 2. 抓灵感（来源、状态都记）

```
$ python scripts/create.py --data ./demo idea --content "穿越者开现代火锅店" --theme 网文 --source 洗澡
已捕获灵感 idea-2026-09-01#1 [网文] 状态=灵感 来源=洗澡
```

## 3. 记作品（走到哪一步填哪一步）

```
$ python scripts/create.py --data ./demo work --title "第一章" --theme 网文 --stage 发布 --quality 4 --hours 3 --source idea-2026-09-01#1
已记录作品 work-2026-09-01#1 [第一章] 阶段=发布 质量4 主题=网文 灵感来源=idea-2026-09-01#1
$ python scripts/create.py --data ./demo work --title "第二章" --theme 网文 --stage 完成 --quality 3
已记录作品 work-2026-09-01#2 [第二章] 阶段=完成 质量3 主题=网文
$ python scripts/create.py --data ./demo work --title "大纲A" --theme 剧本 --stage 启动 --quality 2
已记录作品 work-2026-09-01#3 [大纲A] 阶段=启动 质量2 主题=剧本
```

## 4. 全景

```
$ python scripts/create.py --data ./demo trend
近 30 天创作概览（3 件作品 / 1 条灵感）：
  平均质量 3.00 / 5（趋势：平稳） | 频率 0.70 件/周 | 最长断档 30 天
  完成率 66.7% | 打磨率 33.3% | 发布率 33.3%
  灵感兑现率 0.0%
  主题跨度 2 个（最集中占比 67%）
  创作闭环卡点：样本不足
```

> 注：本例作品都在同日，故趋势显示"平稳"、卡点"样本不足"（<5 件）。真实使用跨多天、多件后，趋势与卡点才会稳定输出。

## 5. 风险扫描（命中中/高严重度 → 退出码 1）

```
$ python scripts/create.py --data ./demo risk
创作风险与模式扫描（近 30 天，3 件作品）：
  平均质量 3.00 | 发布率 33.3% | 频率 0.70 件/周 | 断档 30 天
  创作闭环卡点：样本不足
  [高] 灵感兑现率仅 0.0%（<30%）：抓了一堆点子却很少落地，灵感库在囤积而不是流动
  [高] 最长断档 30 天（>14）：产出一停，手感和热度都掉得快
  [低] 只有 3 件作品（<5），模式判定暂不可靠
  优先行动：每周固定挑 1 条灵感，用「最小可行版本」逼自己当天开个头（标题+三句话大纲就算启动）
```

## 6. 本周唯一动作 + 配套剧本

```
$ python scripts/create.py --data ./demo plan
本周最值得练的一个：
  [高] 灵感兑现率仅 0.0%（<30%）：抓了一堆点子却很少落地，灵感库在囤积而不是流动
  → 行动：每周固定挑 1 条灵感，用「最小可行版本」逼自己当天开个头（标题+三句话大纲就算启动）。
  （另有 2 项次要模式，跑 risk 看全部）
  配套剧本：跑 script --key idea-to-work
```

```
$ python scripts/create.py --data ./demo script --key idea-to-work
瓶颈突破剧本【灵感变作品】Pressfield 2002；Allen 2001
  1. 给每条灵感一个「最小可行版本」：先产出标题+三句话大纲，就算启动
  2. 固定一个捕捉仪式：灵感一来立刻记进灵感库
  3. 每周抽 30 分钟做「灵感盘点」：挑 1 条本周最想做的，当天就开个头
  4. 把「等我有空再做」改成「先做 15 分钟再说」
  示例：灵感：「一个穿越者在现代开火锅店」。最小可行版本：先写 200 字设定+三章大纲...
  避免：把灵感囤成「灵感坟墓」——只收不产。
```

## 关键设计点

- **幂等**：用同 `--id` 重记覆盖原条，不重复计数（修正作品阶段/质量用得到）。
- **实物证据**：`events.jsonl` + `profile.json` + `reports/create-<日期>.md` 全部留本地。
- **退出码**：risk/report 有中/高严重度模式时返回 1，可接定时任务提醒"该干预创作了"。
- **原创量化点**：`infer_bottleneck` 把"卡在哪"从模糊焦虑变成明确环节（灵感变作品 / 启动到完成 / 完成到打磨 / 打磨到发布 / 质量提升 / 持续产出 / 聚焦与跨度 / 登顶健康）。
