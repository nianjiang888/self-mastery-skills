# self-create-agent 更新日志

## v2.0.0（2026-09-01）

首个深度版。定位：创作产出 AI Agent，帮你持续产出、越创越强。

### 能力

- 真引擎 `scripts/create.py`，8 子命令：
  - `set` 创作档案 / `idea` 灵感捕获 / `work` 作品记录 / `trend` 全景 / `review` 单条复盘 / `script` 瓶颈突破剧本 / `risk` 风险扫描 / `plan` 本周计划 / `report` 完整报告。
- 指标：产出频率、质量趋势（前半 vs 后半）、完成率/打磨率/发布率、灵感兑现率、最长断档、主题跨度与集中度、外部反馈均值。
- **原创量化点**：`infer_bottleneck` 推断创作闭环卡在哪一环（灵感变作品 / 启动到完成 / 完成到打磨 / 打磨到发布 / 质量提升 / 持续产出 / 聚焦与跨度 / 登顶健康），类比沟通技能的三层次推断。
- 3 个 resources：create-domains（字段/弱项规则/退出码/边界）、create-models（指标白皮书+阈值）、create-scripts（8 套带出处突破剧本）。
- 14 篇 references 方法论长文，均带年份/书名/研究者出处。
- 实物证据：events.jsonl（type+id 幂等覆盖）+ profile.json + reports/create-<日期>.md。

### 开发期修复的真 bug（先引擎后冒烟抓出）

1. **质量趋势同日误报**：所有作品同日记录时，前半=[最高分]、后半=[其余]会误判"下降"。已加守卫——仅当作品落在 ≥2 个不同日期才计算趋势，否则"平稳"。
2. **剧本库缺失静默失败**：`script` 在 resources 缺失时返回 None 后未报错。已改为 die 退出码 4，并给出可用 key 清单。

### 写作原则

- 包内全中文；slug/CLI/字段名英文技术惯例；第三人称站位，禁用"你是 X"命令式。
- references 按内容自然写扎实，不硬凑字数（用户明确要求）。
- description 写充实大白话，含人搜的词；keywords 打同义词网。

### 合规

- 边界声明：是创作教练与量化工具，不判原创性、不替写、不生成作品内容、不联网。
- 所有数据留本地。
