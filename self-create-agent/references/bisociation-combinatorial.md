# 组合创造力：新意来自"远处的连接"

Arthur Koestler 在《创造的艺术》（1964）里提出**双关连接（bisociation）**：真正的创意，是把两个平时不搭界的思维框架撞在一起，产生第三者。Boden（1990）把这种"把既有概念空间重组"称为组合式创造力。这解释了为什么"主题太散"和"主题太收"都不好。

## 为什么跨度有价值

如果只在一个主题里打转，连接早就被用尽了，边际新意递减。本包 `focus-range` 剧本强调"主线 + 实验田"，主线攒深度、实验田制造远连接——就是这个道理。网文作者去写一条短视频脚本，可能反而给长篇带来新结构；反之亦然。

但跨度要**有锚点**。完全散（本包 `max_theme_share < 0.25` 告警）意味着没有积累，每次都从零开始，连接无从发生。平衡点是：2-3 条主线互相加成，外加一个轻量实验田。

## 为什么"太收"也是病

只写一个主题、一个品类，久了会陷入"自我重复"——读者觉得稳，作者觉得空。本包对 `distinct_themes == 1` 单独告警，不是反对专注，而是反对**只有专注没有探索**。

## 对工具的启示

- `focus-range` 瓶颈：跨度和聚焦要同时有，8:2 是经验比例。
- `idea` 的 `theme` 字段 + 主题分布统计，让你**看见**自己的跨度，而不是凭感觉。
- 组合创造力的前提是"库存够大"——灵感库和作品集越丰，能连接的素材越多。这正是持续记录的价值。

新意不是天上掉下来的，是不同库存之间的碰撞。本包帮你把库存管理起来，连接才有原料。
