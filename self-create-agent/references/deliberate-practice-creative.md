# 刻意练习：为什么"多写"不等于"越写越好"

Ericsson 等人在《刻意练习》（1993, Psychological Review 100(3):363-406）里推翻了一个直觉：水平不是靠枯燥重复堆出来的，是靠**有反馈的、针对弱点的练习**长出来的。一个写了二十年的人，可能只是把第一年重复了十九遍。

## 三个被忽视的前提

1. **明确的最弱项**。泛泛地"多写"不会进步，针对"开头三章节奏拖沓"这种具体短板练才会。本包的 `raise-quality` 剧本要求你先请懂行的人打分、找出最弱单项，下次只练那一项——这就是刻意练习的"针对性"。
2. **即时且可对照的反馈**。Ericsson 指出，没有反馈的练习只是在巩固错误。本包鼓励你记录 `feedback`（外部反馈分），用外部标尺校准自评，正是为了补上这个缺口。
3. **刚好超出当前水平的任务**。和上篇心流一致——太简单无聊、太难焦虑，都不长本事。

## 和"天赋论"的切割

Ericsson 的研究常被简化为"一万小时"，但他本人强烈反对这个说法。关键是**那一个小时里在练什么**。本包不迷信写作时长（`hours` 只是参考，不是进步代理），而盯 `quality_trend`——你在变好还是原地踏步，比写了多少小时重要得多。

## 对工具的启示

- `raise-quality` 剧本：打分 → 找最弱项 → 下次只练那项 → 再打分。一个完整的刻意练习小循环。
- `report` 里的"作品清单"按日期排列，是为了让你看见自己的练习轨迹，而不是一堆孤立的产出。
- 元认知校准（见 metacognitive-calibration 篇）是刻意练习能落地的关键：你的自评准不准，决定了反馈有没有用。

写作是手艺，手艺靠练。但练要练在点上——这是本包把"质量提升"单独列为一个瓶颈环节的原因。
