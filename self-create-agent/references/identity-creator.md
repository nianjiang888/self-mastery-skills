# 创作者身份：你把自己当"创作者"，产出就不同

Daphne Oyserman 的身份动机理论（2011）指出，人会因为一个**身份标签**而调整行为——当"我是某种人"被激活，与之相符的行动会变得自然、不耗能。Ibarra（1999）的"可能自我（possible selves）"进一步说明：人会被"我想成为的那个自己"牵引着行动。

## "我是创作者"为什么是生产力

很多人的创作卡点，根子不在技巧，在身份。他们心里觉得自己是"业余的""还没资格叫创作者"，于是：灵感不敢做、作品不敢发、发完不敢认。本包 `polish-to-ship` 和 `idea-to-work` 两个瓶颈，背后常是这个身份焦虑。

Oyserman 的研究给了一剂解药：**先用行动定义身份，而不是等身份够了再行动**。你每记录一件作品、每发布一次，就是在向自己确认"我是创作者"。本包的 `stage` 推进、每周产出，本质是把这个身份"做"出来。

## 可能自我的双刃剑

Ibarra 也提醒：可能自我如果离现实太远，会变成压力源而非牵引力。所以本包不鼓励你一上来就"我要写一部传世巨著"，而是从"今天产一件微作品"这种够得着的身份行动起步。小赢累积，身份才稳。

## 对工具的启示

- `set` 档案的 `name`/`domain`/`focus`：先给自己一个创作者身份的坐标。
- `keep-output` 的"不间断链条"：每天一笔，是在用行动反复确认身份。
- `report` 的"作品清单"：看得见的数量，是身份最实在的证据——"看，我这一个月真产了这么多"。

身份不是喊出来的，是做出来的。本包帮你把"创作者"从一个模糊的自我期待，变成一组可数、可见、可延续的行动。
