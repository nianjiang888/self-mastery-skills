# 创作阻塞：卡住时，别跟自己较劲

几乎每个创作者都经历过"坐在空白文档前，一个字写不出"。这种**创作阻塞（writer's block）**常被妖魔化成"天赋枯竭"，但研究给出的解释平实得多：它通常是阻力、完美主义、或疲劳的合谋，而非能力问题。

## 阻塞的常见三根源

1. **完美主义卡开头**。总想写出"配得上开头的第一句"，结果永远停在空白。对应本包 `start-to-finish` 瓶颈——解法是"完成线而非完美线"。
2. **孵化被打断**。Wallas 的四阶段（见 creative-process 篇）里，孵化需要你离开问题。越是死盯着，越卡。解法常常是去散步、换件事做。
3. **能量耗尽**。创作是高能耗活动，连续硬写会触底。本包 `max_gap` 不是要你硬撑，而是区分"健康休息"和"无限拖延"。

## 约束反而解放

一个反直觉的发现：给创作**加约束**常能破除阻塞。限字数、限定结构、限定开头三句——框子一给，大脑就不用先解决"写什么"这个开放难题，直接填内容。本包 `idea-to-work` 的"最小可行版本（标题+三句话大纲）"就是这个思路：用最小约束启动。

## 对工具的启示

- 阻塞时先看瓶颈在哪：`start-to-finish`？`idea-to-work`？对症下药，别泛泛"逼自己"。
- `keep-output` 的"微产出也算"：阻塞期降低标准，先动起来，动能会回来。
- 记录 `hours`：若长期高时长低产出，可能是疲劳，该休息而非硬扛。

阻塞不是你的错，是机制问题。本包帮你把"卡住"定位成具体的瓶颈环节，而不是一笔糊涂账——定位清楚了，才有办法。
