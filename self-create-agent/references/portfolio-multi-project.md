# 多作品组合：用"组合管理"替代"孤注一掷"

金融里的组合理论（Markowitz, 1952）核心就一句：别把鸡蛋放一个篮子，用相关性分散风险、平滑收益。创作虽不是投资，但"多作品组合"的思路高度可迁移——尤其对靠内容吃饭的人。

## 为什么单一作品是脆弱的

把全部希望押在一部"大作"上，风险极高：它万一扑了，你的产出曲线直接归零，身份感也受挫。本包 `focus-range` 剧本主张"主线 + 实验田"，底层逻辑就是组合管理：主线是稳定基本盘，实验田是小注探新方向。一两个实验失败无所谓，主线还在。

## 组合带来"期权价值"

每个实验田作品都是一份**实物期权**（Dixit & Pindyck, 1994）：投入小，但万一跑通了， upside 很大。本包鼓励你定期试不同品类，不是让你分心，是在用低成本换取"下一个主线"的发现权。

## 但组合不等于分散到没有重心

组合管理的另一面是**相关性管理**。全散（本包 `max_theme_share < 0.25` 告警）等于没有基本盘，每次从零开始；全收（单主题告警）等于放弃期权价值。健康的组合是：2-3 条主线互相加成 + 1 个实验田。让作品之间能互相引流、互相加成。

## 对工具的启示

- `theme` 字段 + 主题分布统计：让你看得见自己的"组合结构"，而不是凭感觉。
- `focus-range` 瓶颈：跨度和聚焦要同时有，8:2 是经验比例。
- `report` 的"作品清单"按主题可一眼看出哪些是主线、哪些是试探。

创作者不是赌徒。把作品当组合来管理，你抗风险的能力、发现新方向的概率，都会系统性提高。本包把这套思维做成了可追踪的指标。
