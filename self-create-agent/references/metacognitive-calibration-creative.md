# 元认知校准：你的眼力，配得上你的手力吗

Koriat 的元认知校准研究（1993）揭示了一个创作者的隐形陷阱：**人对自己作品的判断，系统性偏离实际**。新手常高估（"我觉得写得挺好"），熟手有时低估，而且这种偏差很稳定、很难靠"多写"自己纠正。Dunlosky & Bjork（2008）进一步指出，未经校准的练习只是在巩固错误。

## 为什么这关涉"越创越强"

本包的 `quality` 是自评，但自评天然不可靠。如果放任自评独大，你可能在重复同一种弱点而不自知——这正是 Ericsson 说的"把第一年重复十九遍"。所以本包做了关键设计：**用 `feedback`（外部反馈）来校准 `quality`（自评）**。

具体做法是元认知校准的经典流程：
1. 先自评（保留内在动机信号）；
2. 请懂行的人给外部分（CAT，见 consensual-assessment 篇）；
3. 对照两者，找出系统性偏差（你总高估开头？总低估结尾？）；
4. 下次带着这个偏差意识去写。

## 校准是"越创越强"的引擎

`quality_trend` 上升，部分原因可能是作品真变好，也可能是你眼力变准、自评更接近实际。无论哪种，闭环都在转。本包 `raise-quality` 剧本把"请人打分 + 对照自评 + 专练最弱项"做成一个可重复的小循环，本质上就是在训练你的元认知。

## 对工具的启示

- `avg_feedback` vs `avg_quality`：两个数字对照，就是校准的素材。
- `raise-quality` 瓶颈：质量偏低时，先校准眼力再谈提升手艺。
- 自评保留（不删）：它是内在动机的度量，问题不在自评本身，在"只有自评"。

手力靠练，眼力靠校。本包把"校准"从一句劝告，做成你每次产出都能跑一遍的小装置——这才是"越创越强"真正的发生机制。
