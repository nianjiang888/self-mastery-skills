# 灵感捕捉系统：别让好点子死在"等会儿记"

Julia Cameron 在《艺术家的路》（1992）里给了创作者两个至今被验证有效的习惯：**晨页（morning pages）**——每天第一件事写三页意识流，把脑子里的杂音倒出来；以及**艺术家约会**——定期独自去接触新鲜刺激。两个习惯的核心都是同一件事：**给灵感一个稳定出口**。

## 捕捉比产生更重要

很多人以为"没灵感"是创作的最大障碍，其实更大的障碍是**灵感来了没接住**。Cameron 的晨页之所以有用，不是因为它产生了多好的句子，而是它训练你把脑子里飘过的东西落下来。本包的 `idea` 子命令就是这么一个轻量捕捉器：一句话、一个来源、一个状态，立刻记，不靠脑子记。

## 灵感库要"流动"不能"囤积"

本包专门设了 `idea_redeem`（灵感兑现率）这个指标，并对 `<30%` 告警。原因来自创作实践：灵感库最容易变成"灵感坟墓"——收藏了一千个想法，一个都没做。Cameron 也强调行动，晨页写下来是为了**随后去活它**，不是为了归档。

## 对工具的启示

- `idea-to-work` 瓶颈：灵感兑现率低，不是你点子少，是你缺"最小可行版本"的启动机制。
- `idea` 的 `status`（灵感/已启动/已转化）让"囤积 vs 流动"变成可看的数字。
- 捕捉要**零摩擦**：本包设计成一行命令记一条，不要求你打开文档、起标题、想清楚——先记，后理。

灵感是创作的原材料。原材料管理差，后面再努力也白搭。本包把"接住灵感"当成创作闭环的第一环，不是装饰。
