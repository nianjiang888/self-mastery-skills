# 心流：创作状态的科学

Csikszentmihalyi 在《心流：最优体验心理学》（1990）里描述的 flow，是创作者最想要的状态——时间消失、自我消失、活儿自己流出来。但心流不是玄学，它有一组可操作的前置条件，这正是 self-create-agent 把"持续产出"当成一个工程问题来管的根本原因。

## 心流的两个旋钮

心流出现在**挑战与技能大致匹配**的通道里：挑战远高于技能 → 焦虑；挑战远低于技能 → 无聊；两者都略高于当前水平 → 心流。这对创作的启示很具体：

- 别一上来就挑"我这辈子最想写的那个大题"。它往往挑战远超技能，只会把你卡在焦虑里动弹不得。
- 也别永远写顺手的、安全的题。那会无聊，无聊会伪装成"没灵感"。
- 挑**略高于当前水平**的题：够不着但垫脚能够着。本包的 `quality_trend` 上升、说明你正待在正确通道里；下降，多半是题选错了难度。

## 心流的前提：清晰目标与即时反馈

Csikszentmihalyi 反复强调，心流需要"目标清晰 + 反馈即时"。这正好解释了为什么"开了头收不了尾"那么常见——没有把大目标切成清晰的下一步，反馈链条就断了。本包用 `stage`（启动/完成/打磨/发布）把一件作品的进度切成四段可见的台阶，每推进一步就有即时反馈，就是在人为制造心流条件。

## 对工具的启示

- `keep-output` 剧本的"固定时段 + 习惯叠加"：心流需要可预期的环境，不能靠"状态好"才进得去。
- `focus-range` 剧本的"主线 + 实验田"：主线维持技能基线，实验田提供适度挑战，两者共同把人稳定在通道里。

心流不是等来的，是设计出来的。本包不教你"放空找灵感"，而是帮你把创作的外部条件搭好，让心流更容易发生。
