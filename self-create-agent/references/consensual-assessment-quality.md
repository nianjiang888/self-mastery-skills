# 质量的共识评估：谁来判定"好不好"

Teresa Amabile 的**共识评估技术（Consensual Assessment Technique, CAT）**（1982 提出，1996 系统阐述）解决了一个老大难问题：创意作品没有标准答案式的"对错"，那质量怎么评？她的答案是：**让该领域里懂行的人独立打分，当他们的评分趋同，就认为作品质量高**。

## 为什么自评不靠谱，又不能不要

Koriat 的元认知校准研究（1993）反复证明：人对自己作品的判断系统性偏离实际——新手往往高估，熟手有时低估，而且这种偏差很稳定。所以本包做了两件事：

1. 保留 `quality` 自评——它是你的内在动机信号（见 intrinsic-motivation 篇），不能丢；
2. 增设 `feedback` 外部反馈分——用 CAT 的思路，请懂行的人给一个独立标尺。

两者对照，长期下来你的"眼力"会追上"手力"。这比闷头自我感觉良好有价值得多。

## 怎么用 CAT 才不踩坑

- **评估者要真懂行**。让外行打分只会引入噪声。本包 `raise-quality` 剧本强调"请一个懂行的人"，不是"请所有人"。
- **独立打分，不讨论**。CAT 要求评估者互不影响，否则从众会污染共识。
- **看趋势不看单次**。一次打分有偶然，本包看 `quality_trend`（前半 vs 后半），用时间序列稀释单次偏差。

## 对工具的启示

- `avg_feedback` 指标：外部标尺的均值，用来和 `avg_quality` 对照。
- `raise-quality` 瓶颈：质量偏低时，先校准眼力再谈提升手艺。
- `report` 同时列出自评与外部反馈，让错位肉眼可见。

质量不是玄学，也不是纯主观。它有一套被研究过、可操作的评估方法。本包把 CAT 简化成一个你能日常用的"请人打分 + 看趋势"循环。
